Policy under test: "Automatic selection" in `style-packs.md` (2026-09-12). This is a prompt-driven selector, so the results below are recorded policy walk-throughs, not deterministic software unit tests. The only mechanical part, the rolling Case guard window and same-batch reservation, is unit-tested in `Gridiron Warrior/scripts/gwqueue/tests/test_style_pack_inventory.py` and exposed by `python -m scripts.gwqueue.pack_history`. This file is a test artifact, not a pack-name registry; the active menu is parsed from `style-packs.md` only.

Re-run these whenever the policy text changes. Record the date, the decision, and the reason. A fixture that starts producing a different answer is either a policy change (document it) or drift (fix it).
