# Examples: made with The Custom Carousel Machine

Both carousels below were generated by the engine from a single sample Brand Profile (`leons-brand-profile.md`, a fictional "Leon's Fixit Shop", a classic-Ford autobody shop, catchphrase "Keep on Truckin'"). Same brand, two different starter packs: that is the white-label point.

- **`keep-on-truckin-editorial-longform.html`**: Editorial Long-Form pack. Cream paper, orange accent, numbered teaching guide.
- **`keep-on-truckin-mono-series.html`**: Mono Series pack. Monochrome, oversized ghost numbers, no accent color.

Open either in a browser (no server needed), click any text to edit, then use the toolbar to export PNGs or a Canva-ready PDF. This is what your own carousels look like once you run Brand Setup with your brand instead of Leon's.
These demos are trimmed for size; carousels the engine generates for you also include inline text-resize controls (click any line, A− / A+).
