# Inspiration images set design direction only; never cloned

During Style Pack authoring a buyer may supply one to three inspiration images (a "moodboard") of designs they admire. Because the product is sold, a tool that reproduces an uploaded design would be a design-ripoff machine: legal exposure for the seller, brand risk, and a contradiction of the Visual Brain's original/documentary ethos. It also breaks white-label, since a cloned look is not the buyer's.

Decision: the Engine reads inspiration images for ABSTRACT DIRECTION ONLY (density, type-vs-photo balance, contrast, casing, type placement, rhythm), synthesizes an ORIGINAL pack spec across the moodboard so no single source dominates, and the buyer's Brand Profile still supplies all color, font, and logo. The Engine never traces or reproduces an uploaded design. A one-line caution in the flow states the buyer is responsible for what they upload and the tool derives direction, not copies.
